# быстрый старт

1. откройте [ссылку](https://hardestbed.dev/).
2. переключайте разделы пунктирными ссылками — каждый экран появляется на месте, прокрутки и хэшей нет.
3. макет удерживается в рамках одного экрана как на десктопе, так и на мобильных устройствах.
4. используйте переключатели в правом верхнем углу главного экрана, чтобы выбрать тему (тёмная / светлая) и язык (en / ru) — выбор сохраняется локально.

# технические заметки

- чистые `HTML` и `CSS`, без фреймворков.
- тёмная и светлая палитры с моноширинной типографикой и пунктирными подчёркиваниями.
- переключение экранов выполняется на JavaScript, URL остаётся чистым, а страница — статичной.
- тема и язык хранятся в `localStorage`, первоначально учитываются системные настройки.
- тексты на двух языках (EN / RU) рендерятся через лёгкий клиентский словарь.
